# 📋 Guide : Ajouter le Projet au CV & LinkedIn

## 🎯 Objectif
Transformer votre projet en un atout impressionnant pour vos candidatures.

---

## **ÉTAPE 1 : Préparer l'URL finale**

### Une fois déployé sur Railway/Render, vous aurez une URL comme :
```
https://algorithmetest-production-xxxx.up.railway.app
```

### Raccourcir l'URL (optionnel mais recommandé)
1. Allez sur [bit.ly](https://bitly.com) ou [tinyurl.com](https://tinyurl.com)
2. Collez votre URL longue
3. Vous obtenez : `https://bit.ly/algo-visualizer`
4. Utilisez cette version courte partout

## **ÉTAPE 6 : Entretien d'embauche**

### Si on vous demande de parler du projet
```
"J'ai créé un visualiseur d'algorithmes pour démontrer ma compréhension
des algorithmes fondamentaux. Le projet inclut :

1. QuickSort : J'ai implémenté 3 stratégies de pivot différentes pour montrer
   comment le choix du pivot affecte les performances.

2. Two Sum : Algorithme optimisé avec recherche binaire (O(n log n))
   plutôt qu'une approche brute-force (O(n²)).

3. Karatsuba : Multiplication rapide exploitant le paradigme 'Diviser pour régner'
   pour réduire la complexité.

Le projet est déployé en production sur Railway avec CI/CD automatique.
Je peux le modifier et les changements sont automatiquement en ligne."
```

### Préparer une démo
```
1. Ouvrir le site en direct
2. Tester les 3 algorithmes avec des données différentes
3. Montrer le code source sur GitHub
4. Expliquer les choix techniques
5. Discuter des améliorations futures
```

## **Checklist finale**

### Avant de partager le lien
- [ ] Site fonctionne 100% (testé sur mobile et desktop)
- [ ] Tous les algorithmes répondent correctement
- [ ] Pas d'erreurs JavaScript (ouvrir Console)
- [ ] Lien fonctionne depuis n'importe quel navigateur
- [ ] README bien documenté
- [ ] Code commenté et lisible

### Avant un entretien
- [ ] Tester le site en direct 2-3 fois
- [ ] Préparer une démo courte (3-5 min)
- [ ] Connaître le code par cœur
- [ ] Préparer 3 questions que vous poseriez

### Avant de le mettre sur le CV
- [ ] Vérifier l'URL encore une fois
- [ ] Tester depuis le navigateur d'un ami
- [ ] Imprimer le CV et vérifier la lisibilité du lien
