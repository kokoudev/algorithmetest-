# ⚡ Démarrage Rapide (2 minutes)

## 🚀 En local (test rapide)

### 1. Installer Python (si pas déjà fait)
```bash
python --version  # Vérifier : doit être Python 3.8+
```

### 2. Cloner le projet
```bash
git clone https://github.com/kokoudev/algorithmetest-.git
cd algorithmetest-
```

### 3. Installer les dépendances
```bash
pip install -r requirements.txt
```

### 4. Lancer le serveur
```bash
python app.py
```

### 5. Ouvrir dans le navigateur
```
http://localhost:5000
```

✅ **Voilà ! Le site fonctionne localement !**

---

## 🌐 En ligne (5 minutes)

### 1. S'authentifier sur Railway
- Allez sur [railway.app](https://railway.app)
- "Login with GitHub"
- Autorisez Railway

### 2. Déployer le projet
- "New Project"
- "Deploy from GitHub"
- Sélectionnez `algorithmetest-`
- Confirmez

### 3. Attendre (2-3 minutes)
- Railway construit et déploie automatiquement
- Vous recevrez une URL : `https://algorithmetest-xxxx.up.railway.app`

✅ **Voilà ! Votre site est en ligne !**
